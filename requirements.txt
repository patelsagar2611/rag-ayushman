# CPU-only torch, resolvable from THIS FILE ALONE -- Hugging Face Spaces builds
# from requirements.txt and nothing else, so the old two-step install (torch from
# the PyTorch index first, then this file) is not available there.
#
# --extra-index-url is a HINT, not a constraint: pip considers both indexes and
# picks by version precedence, so a newer torch on PyPI would win and this line
# would do nothing on its own. The "+cpu" local-version suffix is what makes it
# binding -- that suffix exists ONLY on the PyTorch index, so resolution either
# finds the CPU wheel or fails loudly.
#
# Verified 2026-08-30 by resolving the Linux/cp312 graph with --dry-run --report:
# picks torch-2.13.0+cpu-cp312-cp312-manylinux_2_28_x86_64.whl from the PyTorch
# index, with ZERO nvidia-*/cuda/triton packages in a 111-package closure. The
# absence of those packages is the real signal, not the version string.
#
# manylinux_2_28 means the host image needs glibc >= 2.28. Debian bookworm (2.36)
# and Ubuntu 22.04 (2.35) both clear it.
--extra-index-url https://download.pytorch.org/whl/cpu
